Descriptions

Short description2–3 sentences

FactLedger is a read-only Solana wallet intelligence API. It turns raw on-chain transaction data into deterministic risk and intelligence scores — every score cites the real evidence behind it, and the platform returns "unknown" instead of guessing when data can't be verified.

Problem & solutionfull detail field

Solana wallet analysis tools today either claim to detect DEX activity without verifying program IDs — often wrong — or hide behind opaque ML scores nobody can audit. FactLedger fixes both. Every DEX protocol detection is checked against verified program IDs and labeled confirmed / candidate / unknown honestly, never inflated to look more certain than it is. Every intelligence and risk score is a deterministic weighted formula built from named, explainable factors, returned alongside the exact transactions and numbers it was derived from. The full pipeline — RPC read, protocol identification, behavior analysis, scoring, evidence citation — is built and tested: 133 passing tests including an automated determinism check that runs the scorers twice on identical input and asserts byte-identical output. CI is green end to end on GitHub's own runners. The platform never fabricates data: prices, fees, and blockchain facts are either real or explicitly null — never guessed.
