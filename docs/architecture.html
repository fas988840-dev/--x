Writes to Chain
read-only by design
🔒
No writes · No signing · No keys SolanaRpcClient calls only read methods. Nothing requests private keys, seed phrases, or credentials.
🎯
Never fabricate data Unknown prices, fees, and block times return null or 'unknown', never a guess or default.
🔁
Deterministic scoring Same input always produces identical scores. A CI test calls every scorer twice and asserts exact equality.
🧮
String-precision amounts Lamports and raw token amounts are kept as string throughout — never cast to number where float precision could be lost.
💬
LLM only rephrases ChainGPT receives already-computed facts in the prompt and is instructed to add nothing. Every structured field is built from deterministic pipeline output.
⚠️
Disclaimer on every score Intelligence, risk, and analysis endpoints always include a disclaimer: not financial advice.
