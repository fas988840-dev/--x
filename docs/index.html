FactLedger

A read-only Solana wallet intelligence platform. Every score cites the real transactions, program IDs, and factors it's based on — and says "unknown" instead of guessing when it can't verify something.

What it does

FactLedger turns raw Solana RPC data into deterministic behavioral metrics, an intelligence score, and a risk assessment for any wallet address — through a REST API, an MCP server, and a web dashboard. It never signs transactions, never requests private keys, and never fabricates a value it can't verify.

The pipeline

Solana RPC → TransactionRetriever (signatures, transactions, instructions) → InstructionParser (program identification: confirmed / candidate / unknown) → BehaviorAnalyzer (frequency, failure rate, diversity, timing) → IntelligenceScorer (activity / sophistication / consistency / efficiency) → RiskAssessor (failure-rate / concentration / volatility / pattern factors)

What's real today

VERIFIEDDeterministic scoring

The same input into the scoring functions is asserted, in CI, to produce byte-identical output every time — not just claimed.

VERIFIEDEvidence Engine

Every transaction cited turns into a real, per-instruction evidence entry — signature, slot, program, and a confidence value from a fixed, documented mapping.

CANDIDATERaydium / Jupiter detection

Verified program IDs and instruction-type discriminators identify swap instructions from these two protocols. Amount/mint extraction is intentionally not implemented yet — see the repo's CLAUDE.md for why.

VERIFIEDReal price data

Token prices come from CoinGecko's public API — null on any failure, never a hardcoded guess.

Interfaces

  • REST API — wallet analysis, risk, evidence, research, and a deterministic agent router
  • MCP server — the same capabilities as callable tools for any MCP-compatible AI client
  • Dashboard — a web UI over the same API

This is a pre-launch, proof-of-concept project. No external users or usage metrics yet. Intelligence and risk scores are derived from observable on-chain behavior only — not financial advice, and not a recommendation. Source code is proprietary; contact for access.
