Solana · Read-Only · Evidence-Backed

Nothing here is guessed.

FactLedger turns raw Solana wallet activity into deterministic scores that cite their own evidence — every transaction, program, and factor a score is built from is named. Where the platform can't verify something, it says unknown, not a plausible-sounding number.

How a wallet becomes a score

01

One linear pipeline, five stages, no step that invents a value the one before it didn't actually produce.

1
rpc.read Signatures, transactions, and instructions, read directly from Solana RPC.
2
program.identify Each instruction's program is classified confirmed / candidate / unknown — never collapsed into one.
3
behavior.analyze Frequency, failure rate, token/program diversity, timing — computed, not estimated.
4
score.compute Intelligence and risk scores, each a weighted sum of named factors you can see.
5
evidence.cite Every score ships with the transactions and factors it came from.

What's actually verified

02

A running account, not a features list. Two states only — nothing is marked done until it is.

Verified

Deterministic scoring

The same input into the scoring functions is asserted, in CI, to produce byte-identical output — checked on every push, not asserted in a doc.

Verified

Evidence Engine

Every cited result traces to a real instruction — signature, slot, program — with a confidence value from a fixed, published mapping.

Candidate

Raydium / Jupiter detection

Program IDs and instruction-type discriminators are verified for both. Amount and mint extraction is not — so it's left null, not guessed.

Verified

Real price data

Token prices come from CoinGecko's public API. Any failure returns null, never a stale or hardcoded fallback.
