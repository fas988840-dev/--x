# FactLedger Verification Artifacts

This directory contains verification artifacts that are produced only from reproducible, live checks.

## Evidence integrity rules

- Do not commit fabricated, estimated, or manually invented API responses.
- Raw proof files must be copied from the actual live response without modification.
- Record verification timestamps in UTC and Asia/Riyadh when a proof is frozen.
- Keep ChainGPT verification separate from Solana RPC/WebSocket benchmark evidence.
- Never commit API keys, RPC tokens, private keys, seed phrases, signing material, or other secrets.
- Sanitized RPC URLs may be included in reports; raw secret-bearing URLs must never be logged or committed.

## Planned artifacts

### ChainGPT

- `factledger-chaingpt-proof.json` — raw live API response after ChainGPT is verified on production.
- `CHAINGPT-LIVE-VERIFICATION.md` — human-readable reproduction notes and timestamps for the same live check.

These two files must not be created as successful proof until the production endpoint is checked and the returned `summarySource` is confirmed from the live response.

### Solana network quality

- `solana-rpc-ws-benchmark.json` — machine-readable output generated by `scripts/verify-solana-rpc-ws.mjs`.
- `SOLANA-RPC-WS-VERIFICATION.md` — optional reviewer summary generated only after a real benchmark run.
