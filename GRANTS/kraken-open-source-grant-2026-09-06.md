### Core description

FactLedger is an MIT-licensed, read-only Solana wallet intelligence API and MCP tooling. It never fabricates blockchain data: values are either verified from on-chain/provider evidence or returned as null rather than estimated. Deterministic wallet scores include the specific transactions and named factors behind them so results can be independently recomputed.
