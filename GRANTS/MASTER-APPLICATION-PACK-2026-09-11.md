## Core project description

FactLedger is an open-source, read-only Solana wallet intelligence and verification API. It analyzes wallet activity using verifiable on-chain data, produces deterministic risk signals, and links outputs to transaction-level evidence so results can be independently checked. Values are either verified from available data or returned as null rather than fabricated. The project already has a live API, public demo, GitHub repository, CI workflows, deployment infrastructure, and verification tooling.

## Problem

Blockchain wallet analysis products can return opaque scores, estimated values, or conclusions that are difficult to independently verify. FactLedger addresses this by making wallet intelligence reproducible: outputs are tied to on-chain evidence and are designed to be independently checked against Solana data.

## Why this team

FactLedger is currently founder-led and built by a solo developer who has designed, deployed, and maintained the live product end-to-end. This includes the Solana wallet intelligence backend, deterministic risk logic, transaction-level evidence, public API, live demo, CI workflows, deployment infrastructure, and verification tooling. Because the core product already exists as a working MVP, grant funding would accelerate a proven development path rather than fund an idea from scratch.

## Public-good case

FactLedger is designed as open-source public infrastructure for the Solana ecosystem. Developers can use its wallet intelligence, transaction evidence, verification tooling, and documentation without relying on opaque proprietary scoring systems. By publishing reproducible evidence and keeping the core MIT-licensed, the project can improve transparency, developer tooling, security research, and trust across the ecosystem.

## Competitive differentiation

FactLedger competes with wallet analytics, blockchain explorers, risk-scoring services, and Web3 data APIs. Its differentiation is an evidence-first model: outputs are tied to specific on-chain evidence, unavailable values are not invented, and results are designed to be independently reproducible. The MIT-licensed open-source core also reduces vendor lock-in for developers.
