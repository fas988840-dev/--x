## Superteam — Global / Saudi-eligible grant template

### One-line description

FactLedger is an open-source Solana wallet intelligence API that produces deterministic risk analysis with transaction-cited evidence and explicit UNKNOWN/null states instead of guesses.

### Problem

Wallet scores often look precise while hiding the evidence and assumptions behind them. Developers, agents and audit-oriented workflows need to know which transactions produced a risk conclusion and which values were unavailable.

### Solution

FactLedger reads public Solana activity, calculates deterministic wallet intelligence and risk metrics, and returns evidence tied to the underlying transactions. Unsupported or unverifiable facts remain explicit unknowns.

### Why this matters to Solana

The project provides reusable open-source developer infrastructure for transparent wallet intelligence on Solana. It is designed for wallets, fintech applications, agents, security research and integrations that need reproducible evidence rather than opaque scoring.
