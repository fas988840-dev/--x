# FactLedger — Strategic Acquisition Teaser

> Confidentiality-safe draft. Use only verified claims. Do not disclose secrets, customer-confidential information, or unsupported metrics.

## Company / product

FactLedger is an evidence and risk intelligence layer for Solana wallets and transactions. It provides structured wallet behavior analysis, transaction parsing, attributable evidence, explainable risk, and machine-readable outputs through API, dashboard and agent workflows.

## Strategic rationale

A strategic buyer would not be acquiring only source code. The intended value stack is:
- Solana-specific risk/evidence architecture
- accumulated Evidence/Risk Graph and historical intelligence with provenance
- production integrations and operational knowledge
- external API/agent distribution
- customer/design-partner workflows
- recurring revenue and brand, once established

## Product assets

Implemented:
- Solana RPC integration layer
- Wallet Analyzer
- Transaction Parser
- Evidence Engine
- Risk Engine
- AI Agents
- ChainGPT integration with deterministic fallback
- API + documentation + automated tests
- dashboard
- production Render service

Items should be upgraded to "verified production" only after external end-to-end proof.

## Potential buyer categories

- blockchain analytics / compliance vendors
- wallet security and transaction simulation providers
- explorers and wallet infrastructure companies
- crypto risk/intelligence platforms
- security vendors expanding to Solana
- agent / developer infrastructure platforms
- exchanges, custodians or institutional platforms with Solana risk workflows

## Buyer thesis

The strongest acquisition case is reached when reproducing FactLedger internally would require not only engineering time, but also rebuilding historical evidence, integrations, customer workflows, operating knowledge and distribution.

## Metrics to disclose only when sourced

- ARR / MRR
- paying organizations
- active API integrations
- monthly analyses / API calls
- gross margin
- retention / expansion
- design partners
- proprietary intelligence coverage
- uptime / latency / error rate

## Transaction evaluation framework

Compare offers on total expected value:
- cash at close
- equity/rollover
- earn-out amount, probability and measurement rules
- escrow/holdback
- IP scope
- data rights
- employment or consulting obligations
- exclusivity / non-compete restrictions
- representations and warranties
- tax/legal consequences

A headline price without these terms is not a comparable offer.

## Process rule

Do not run a broad sale process before FactLedger has credible proof unless an inbound strategic offer is unusually strong. Maintain buyer readiness early so inbound interest can be evaluated quickly without signaling urgency.
